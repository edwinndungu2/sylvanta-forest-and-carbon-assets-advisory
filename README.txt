sylvanta/

## Open locally
Open the `sylvanta` folder in VS Code, then open `index.html` in a browser.
You can also use the VS Code Live Server extension.

## Before publishing
The website lists the founder's supplied email and phone number. Confirm these details and any additional company claims before publishing. Add only verified founder qualifications, project experience, memberships and certifications.
